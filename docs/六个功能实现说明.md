# BiliWhaleMusic 六个功能 · 实现说明

> 对应 `docs/功能实现-AI提示词.md` 里的 P0 + ①~⑥，均已落地在代码里。

## P0 播放状态转发扩展
- `renderer/player/app.js`：`syncPlayback()` 追加 `author / bvid / cid / page`。
- `main.js`：`ipcMain.on('playback:update')` 转发给桌宠时补 `duration / author / bvid / cid / page`，
  并顺手调用 `recordHistory()` 记录听歌历史。

## ① 情绪系统
- `renderer/pet/pet.js`：`setMood()` + `pickMood()`，按标题/时长/是否合集判断 `hype | chill | happy`。
- `renderer/pet/index.html`：`body.mood-*.action-dance #whale` 三套摇摆动画（快摇 / 慢摇 / 弹跳）。

## ② 弹幕氛围
- `main.js`：`ipcMain.handle('pet:danmaku')` 抓 `https://api.bilibili.com/x/v1/dm/list.so?oid=<cid>`，
  正则解析 `<d p="...">`，去重、截断 200 条，`Map` 缓存（同一视频只请求一次）。
- `preload-pet.js` → `pet.js`：切歌时挑一条 5~30 字弹幕，`say('弹幕说：…', 4500)`，失败静默。

## ③ 成长系统
- `src/store.js`：新增 `listenWave / petLevel / petExp / listenHistory`。
- `main.js`：`growth()` 用累计听歌秒数算音浪与等级（`1 + floor(sqrt(wave/600))`），`sampleStats()` 一并下发；
  面板收起但正在播放时也会低频（6s）推送，保证升级不丢。
- `renderer/pet/index.html`：新增「成长」卡片（Lv、音浪、进度条、距下一级分钟数）。
- 升级时 `pet.js` 冒泡「升到 Lv.N 啦」。

## ④ 歌词哼唱
- `renderer/player/app.js`：`syncLyrics()` 在活动行变化时 `bridge.setLyricLine(text)`；切歌先发空串。
- `main.js`：`ipcMain.on('lyric:line')` 去重后转发。
- `renderer/pet/pet.js`：`sayLyric()` 用 85ms/字 的打字机效果写气泡；空串回退「♪ 曲名」。

## ⑤ 听歌时光机
- `main.js`：`recordHistory()` 按天写 `listenHistory`（每天最多 50 条，最多 400 天）；
  `checkFlashback()` 启动 3 分钟后、之后每小时查「去年今天」，有记录就发 `pet:flashback`。
- `renderer/pet/pet.js`：`onFlashback` → 冒泡「📅 去年今日你在听《…》」。

## ⑥ 摸头彩蛋
- `renderer/pet/pet.js`：`patCount` 5 秒归零；第 3 下转圈（`action-twirl`），第 5 下爱心换金星，
  23:00–06:00 摸头改说「这么晚还在摸我，快去睡觉啦～」；单击开面板的语义不变。

## 歌词匹配的健壮性
- `src/lyrics.js`：候选按分数排序后最多试 3 个，要求歌词里至少 4 行时间戳；
  歌名/歌手都必须能和候选对上（`artistOk`），避免把翻唱当原唱；匹配不到就回退显示歌名。
